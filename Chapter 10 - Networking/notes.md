### ipv4 :
It is based on 32-bit address & having four octets seperated by dots.    
**Ex :** `192.168.10.100`

### ipv6 :
It is based on 128-bit address & were written in 8 groups & each group contains hexa decimal numbers (16) & seperated by colons.     
**Ex :** `fe80:badb:abe01:45bc:34ad:1313:6723:8798`

### Subnet Mask :
- To know which network a computer belongs then subnet mask is used.
- Subnet mask maybe written in CIDR (Classless Inter-Domain Routin).    
**Ex :** `192.168.10.100/24`

### MAC Address :
- Ecah network device also have 12-byte MAC Address.
- Each MAC address consists os two parts, first 6-bytes is vendor ID, next 6-bytes is unique node ID.   
**Ex :** `00:0c:29:7d:9d:17`

### Protocol & Ports :
- On the node you typically run services like webservers or an FTP server.
- To identify these services port addresses are used
- Specific protocol is used between IP address and port address
    - TCP
    - UDP
    - ICMP

### Fixed IP address :
Used for servers and other computers that always need to be available at that same IP address.

### Dynamically assigned IP address :
Used for end user's devices & for instance in cloud environment.
